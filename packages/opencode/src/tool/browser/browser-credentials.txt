- Website logins for the Desktop browser tab, imported from the Chrome password CSV export
- import: reads the CSV (default: Contraseñas de Chrome.csv in Downloads) into the OS-keychain encrypted store; status: lists stored domains and usernames, never passwords; login: fills the login form of the current tab page with the stored credential for its domain, then verify with browser_snapshot; forget: deletes stored logins, optionally limited by domain and username
- Passwords never leave Desktop main: tool output contains domains, usernames and counts only
- Desktop only: fails closed when there is no Desktop parent process
